# Brutalist Industrial — Design System

## Design Name
Brutalist Industrial

## Concept
Raw honesty — exposed grid lines, monospace type, data-as-design. The site rejects ornamentation entirely. It says: "We don't need to look pretty — our track record speaks for itself." Think Bloomberg terminal meets brutalist architecture.

## Typography
- **Primary**: JetBrains Mono (Google Fonts, weights: 400, 500, 700, 800)
- No italic, no thin weights. Bold and medium only.
- Everything in monospace — headings, body, navigation, buttons

## Color Palette
| Token | Hex | Usage |
|---|---|---|
| Background | `#0a0a0d` | Page background (near-black) |
| Surface | `#141418` | Card/container backgrounds |
| Foreground | `#e8e8e8` | Primary text (off-white) |
| Accent / Amber | `#f59e0b` | Calls to action, highlights, active states |
| Muted | `#6b7280` | Secondary text, metadata |
| Border | `#2d2d35` | Structural borders |
| Error / Alert | `#ef4444` | Warnings, errors |

## Layout
- Visible structural borders on all containers (thin `#2d2d35`)
- Data-ticker style horizontal rules
- Monospaced table-like layouts
- Minimal padding — dense but ordered
- Section dividers are thick visible lines
- All containers have visible borders

## Animations
- Typewriter-style text reveals (character-by-character)
- Blinking cursor on hero text
- Terminal-style scan line effect on images
- Counter animations that tick up on scroll
- Subtle CRT scan line overlay on the entire page
- Glitch effect on hover (subtle)

## Tone
Utilitarian, raw, data-centric, unapologetically industrial. No rounded corners. No gradients. No shadows that aren't hard and angular.
