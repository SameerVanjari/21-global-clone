# Retro-Futuristic / Cyber-Trade

**Concept**: "What if trading terminals were designed in 2099?" Holographic glass-morphism, neon-accented, cyberpunk-meets-hedge-fund. Dark, glowing, data-dense but sleek.

## Typography

- **Display**: Sora (Google Fonts, weights: 200, 300, 400, 500, 600, 700) -- geometric, futuristic
- **Data/Mono**: JetBrains Mono (Google Fonts, weights: 400, 500) for data elements
- Wide tracking on titles, tight on data

## Color Palette

| Token | Value |
|---|---|
| Background | `#06060b` (deep void black with slight blue) |
| Surface | `#0d0d1a` |
| Glass | `rgba(255, 255, 255, 0.03)` -- frosted glass cards |
| Primary Cyan | `#00f0ff` (electric cyan neon) |
| Secondary Magenta | `#ff00e5` (hot pink/magenta neon) |
| Tertiary Amber | `#ffaa00` (amber data accent) |
| Text Primary | `#e0e8ff` (cool white) |
| Text Muted | `#667799` |
| Border Glow | `rgba(0, 240, 255, 0.2)` |

## Layout

- Glass cards (backdrop-filter: blur) on dark gradient backgrounds
- HUD-style data panels overlaid on sections
- Diagonal section splits (angled dividers)
- Holographic globe/map element in background
- Grid overlays with subtle opacity
- Thin glowing borders (box-shadow glow, not thick lines)

## Animations

- Holographic shimmer across glass cards (CSS gradient animation)
- Scanning line that moves top-to-bottom across sections
- Data stream effects (raining characters)
- Globe rotation on scroll
- Magnetic hover on interactive elements
- Glitch text reveals
- Neon pulse breathing effect
- Particle field background

## Tone

Blade Runner meets Bloomberg Terminal. High-tech, premium, faintly dystopian but luxurious. The future of global trade.
