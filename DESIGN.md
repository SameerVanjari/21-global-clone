# Swiss International Style

**Concept**: Helvetica. Grids. Objectivity. Mathematical precision. The company's Swiss presence made literal — this is the website as a Swiss watch. Every element placed with purpose. No decoration, only information.

## Typography
- **Primary**: Inter (Google Fonts, weights: 300, 400, 500, 600)
- One typeface only. Three weights.
- Flush left, ragged right. Always.

## Color Palette
| Token            | Hex       | Usage                                        |
|------------------|-----------|----------------------------------------------|
| Background       | `#ffffff` | Pure white — full page background            |
| Paper            | `#fafafa` | Slightly off — section backgrounds           |
| Foreground       | `#111111` | Near-black — primary text                    |
| Muted            | `#767676` | Secondary text, captions                     |
| Accent Red       | `#e63946` | Swiss red — used sparingly, like a red pen mark |
| Border           | `#e5e5e5` | Very light — dividers, thin rules            |
| Border Strong    | `#cccccc` | Stronger borders                             |

## Layout
- Strict 12-column modular grid
- Everything aligned to the grid
- Massive white/negative space
- Photography in perfect circles only (no rounded rectangles)
- Left-aligned everything — no centering
- Thin, precise rules between sections
- No shadows. No gradients. No rounded corners beyond perfect circles.

## Animations
- Clean horizontal reveals (elements slide in from left only)
- Grid lines assembling on scroll
- Linear transitions only — no bounce, no spring
- Numbers that count up precisely
- Staggered reveals precisely timed to a grid rhythm

## Tone
Cold precision. Swiss objectivity. Mathematical. The design says "we are exact." Every pixel intentional.
